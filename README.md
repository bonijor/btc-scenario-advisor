# BTC Scenario Advisor · MVP

Aplicación web estática y PWA para analizar escenarios probabilísticos de Bitcoin.

## Funciones incluidas

- Precio y velas públicas BTC/USDT desde Binance.
- WebSocket para actualización en vivo.
- Horizontes 1m, 5m, 15m y 1h.
- RSI 14, MACD, EMA 20/50/200, ATR y volumen relativo.
- Soporte, resistencia y posición dentro del rango.
- Probabilidades alcista, bajista y lateral, sumando 100%.
- Activación, invalidación, riesgo y confianza.
- Alertas locales con Notification API.
- Historial local.
- Fallback de demostración cuando la fuente no responde.

## Publicación

El sitio está preparado para GitHub Pages desde la raíz de la rama `main`.

## Aviso

Es un MVP informativo. No ejecuta operaciones ni reemplaza asesoramiento financiero profesional.
